# Diplom_2

Автоматизированные тесты для проверки API сервиса [Stellar Burgers](https://stellarburgers.education-services.ru/).

Проект содержит полное покрытие API-тестами следующих функциональностей:

1. Создание пользователя (`POST /api/auth/register`)
- Создание уникального пользователя
- Попытка создания существующего пользователя
- Создание без обязательного поля `email`
- Создание без обязательного поля `password`
- Создание без обязательного поля `name`
2. Логин пользователя (`POST /api/auth/login`)
- Успешный логин с корректными данными
- Логин с неверным email
- Логин с неверным password
- Логин с полностью неверными credentials
3. Создание заказа (`POST /api/orders`)
- Создание заказа с авторизацией
- Создание заказа без авторизации
- Создание заказа с валидными ингредиентами
- Создание заказа без ингредиентов (негативный тест)
- Создание заказа с невалидным хешем ингредиентов (негативный тест)
- Создание заказа с одним ингредиентом
- Создание заказа с дублирующимися ингредиентами

# Инструкция по запуску:
1. Создание виртуального окружения
python -m venv venv

2. Установка зависимостей
pip install -r requirements.txt

4. Запуск тестов
Запуск всех тестов:
pytest

5. Генерация Allure отчета
Запуск тестов с созданием результатов:
pytest --alluredir=allure-results

Генерация и открытие HTML отчета:
allure serve allure-results
